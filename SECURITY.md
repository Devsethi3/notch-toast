# Security Policy

## Supported versions

Security fixes are applied to the latest published version of `notch-toast`.

| Version | Supported |
| --- | --- |
| Latest release | Yes |
| Earlier releases | No |

## Reporting a vulnerability

Please do not open public GitHub issues for suspected security vulnerabilities.
Instead, contact the maintainer through the
[Dev Sethi GitHub profile](https://github.com/Devsethi3) with a clear
description, affected version, reproduction steps, and potential impact.

You can expect an acknowledgement within 7 days. After the report is reviewed,
the maintainer will coordinate a fix and disclosure timeline with you.

## Scope

This policy covers the published `notch-toast` package, its CLI, the shadcn
registry entry, and the documentation site source in this repository.
